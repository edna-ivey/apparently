# Apparently You Dailies: One-Pass Master Editorial Review Contract

Owner directive, 2026-10-19. This file is an instruction record, not approval of unpublished content or production changes.

## Required complete record for EVERY Daily
1. Stable Daily ID, Free or Apparently Private, and editorial status (approved exact copy / draft / cut / proposed revision).
2. Exact question text.
3. Every answer option, exact copy (two choices for true Would You Rather / This or That; otherwise as authored).
4. For EACH answer, the reveal title AND full reveal body.
5. For EACH answer, the complete proposed personality evidence mapping: every genuinely supported trait/pole with 1, 2, or 3 points and a short reason grounded in the answer. Include all applicable traits. No maximum number of mapped traits, no 3-trait cap, no arbitrary limit. An answer may legitimately map to ten or more traits/poles. Do not add weak mappings merely to fill slots. Do not silently treat code limitations as editorial rules.
6. Distinguish exact owner-approved wording from Forge proposals; no scoring mappings are locked until owner approves them.
7. Any character/song-based answers include character + movie/show or song + artist + explanation, and no duplicate individual character or song across Free and Private.

## Workflow
- Assemble the FULL surviving Daily collection in ONE navigable master review file, grouped Free and Private, with IDs and clear statuses. Include all questions, answers, reveals and mappings together so owner reviews ONCE, scanning and flagging only exceptions.
- Preserve every prior owner approval and every CUT. Never infer an approved question concept implies approved reveals or scoring.
- SAVE master file on the user's Mac first; read back to verify. Then commit/push to GitHub when available, and verify remote status. No chat-only canonical record.
- No changes to live app content, production database, scheduling, or scoring implementation without separate explicit authorization.
- If a mapping references a trait/pole absent from the current taxonomy, flag the mismatch for decision rather than inventing production traits.
