# NORMALIZATION
Personality should NOT accumulate unlimited raw points.
Otherwise someone who answered 500 questions would automatically appear more extreme than someone who answered 50.
Convert:
-2 → -1.0
-1 → -0.5
+1 → +0.5
+2 → +1.0
For each dimension:
normalizedScore =
average of relevant normalized evidence
Approximately:
-1 = strongly negative pole
0 = mixed/center
+1 = strongly positive pole
More answers increase CONFIDENCE.
They do not automatically increase extremity.

# IMPORTANT: DO NOT CONFUSE SCORE WITH DISTINCTIVENESS
The user and I specifically discussed this.
A trait should NOT become Top 7 simply because it has the highest raw score.
We care about:
1. DIRECTION
Where on the spectrum is the user?
2. INTENSITY
How far from neutral?
3. CONFIDENCE
How much evidence supports it?
4. BREADTH
Did this show up across multiple kinds of situations?
5. EVENTUALLY POPULATION DISTINCTIVENESS
Once Apparently has enough users:
How unusual is this pattern relative to the population?
Example:
Planner score is high.
But if almost everyone scores that high, it may not be especially defining.
Meanwhile Trust First might be slightly lower but exceptionally unusual.
Eventually population percentiles can improve signature ranking.
Do NOT implement population comparisons prematurely when we lack enough data.
